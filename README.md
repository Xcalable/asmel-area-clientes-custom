# Clínica Asmel — Área de clientes

Child theme de WordPress. El **área de clientes de Clínica Asmel la hice desde cero**:
registro, aprobación, login, dashboard, informes, comprobantes, carga de documentos
y conversión a PDF.

Además migré la base histórica de la clínica (más de 10 años) a WordPress,
con un registro para que cada usuario blanquee su contraseña y complete
datos que el sistema anterior no tenía, y sync legacy (ZIP/DBF).

> English: [*README.en.md*](./README.en.md)

## Incluye
- Área de clientes armada desde cero
- Registro, blanqueo de contraseña y datos faltantes
- Aprobación de usuarios
- Dashboard de informes y comprobantes
- Migración / sync legacy → WordPress
- Conversión DOC/DOCX → PDF

## Stack
WordPress (child theme) · PHP · JavaScript · CSS · DBF/ZIP
